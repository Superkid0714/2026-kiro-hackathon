# Change Request Log — Spec 변경 요청

> 구현 Agent가 설계·요구사항 변경이 필요할 때 아래 양식을 작성한다.
> Kiro가 검토 후 승인/반려하며, 승인 시 Spec을 직접 수정한다.

---

## 양식

```markdown
### CR-[번호] — [제목]

- **요청 Agent**: (Codex / Claude Code)
- **요청일**: YYYY-MM-DD
- **대상 Spec**: (예: `.kiro/specs/matching/design.md`)
- **관련 Task**: (예: TASK-MATCH-02)
- **변경 이유**: (현재 설계로는 구현 불가능한 이유 또는 개선 사유)
- **영향 범위**: (변경 시 영향받는 Task, 모듈, 인터페이스)
- **제안 내용**: (구체적인 변경 제안)
- **승인 상태**: `PENDING` / `APPROVED` / `REJECTED`
- **검토 의견**: (Kiro가 작성)
```
